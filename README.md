# Cartel

A shared-household grocery list app with a Shopping Mode that follows the order of the store you are standing in. Expo (React Native Web) client in `mobile/`, Supabase backend, hosted on Vercel.

## Run locally

```
npm --prefix mobile run web -- --port 8082
```
